### **Product Description**

TAK Tracker is a lightweight standalone android application for sending location information to a TAK Server.  Additionally it supports sending chat and emergency messages.

TAK Tracker is a standalone plug-in designed to keep track of users in a TAK environment who do not have ATAK installed. ATAK/WinTAK users enrolled on the same server will see the TAK Tracker user markers on their map interfaces. Selecting a user marker will show that device's speed, heading, altitude and location data.

### Product Description

The Team Awareness Kit (TAK) Tracker (also known as the Tactical Assault Kit in the Department of Defense) is a lightweight, send-only application designed to enable easy integrations into existing training and operational workflows. The application is designed from the ground-up in iOS and connects to your favorite TAK servers with either Data Packages or Certificate Enrollment. In addition, TAK Tracker can broadcast its information to the local network like you would expect from any TAK application.

### TAK Tracker contains with the following features:

* Full support for Data Packages and Certificate Enrollment
* Location / CoT broadcast over UDP
* Emergency Beacon support
* Support for Standard, Hybrid and 3D Maps
* Ability to change all measurement types, including MGRS
* Full support for continuously running in the background with low power draw

### Additional features coming in the next release:

* TAK Chat Support
* Group/Channel Support
* QR Code Enrollment

### System Requirements:

* Supports iOS 15.4 and later versions
