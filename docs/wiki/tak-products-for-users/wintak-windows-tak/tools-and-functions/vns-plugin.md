## **Plugin Description**

The Vehicle Navigation System (VNS) plugin performs two major functions. The first is that it allows routes in TAK to be aligned to the road system. The second is that it feeds the Augmented Reality System-Navigation (ARES-N) application with vital information, such as the device's location, pertinent situational awareness markers, and turn-by-turn style driving directions.

Road system data is procured using the PAR osm-routing-engine project.
