## **Plugin Description**

TAK Replay allows users to record map events and chats in real time to replay later. The recording area can be customized by zoom level and viewing region. Each recording can be replayed in a Timeline Viewer that allows the user to view events in real or accelerated time. Additionally, users can download and save from the TAK Server all map events and chats that occurred during a user-specified time frame.
