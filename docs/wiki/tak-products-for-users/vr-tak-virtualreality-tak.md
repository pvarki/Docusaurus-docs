## **Product Description**

The VR-TAK development effort leverages virtual reality to create a virtual world capable of interacting with and manipulating data in the TAK ecosystem for mission planning and heads up augmented reality operation. The 3-D content, created by FMVto3D, can be viewed using: commercial virtual reality (VR) hardware, through a desktop using video game controllers/keyboard and mouse, or handheld on TAK devices. VR-TAK and FMVto3D software is government owned and operated, just like TAK. All necessary hardware/software is commercially available for less than $13k/kit, fits into a man-portable pelican case, and can be operated in austere environments.

### **Dataset formats currently supported**

* Terrain Elevation -DTED, Quantized Mesh, Mapbox
* 3D Tile format (gltf, b3dm, glb, geojson (polygons only)
* Pointclouds (xyz, pts, txt, las, lax, e57)
* Several raw mesh formats such as OBJ, FBX, DAE (Collada), 3DS, BLEND, etc.
* Geo-tagged datasets from services such as BuckEye, Context Capture, FG3D, Hivemapper, CORE 3D, NearMap3D, PeARL, etc.
* KML/KMZ files
* Mapbox vector tiles

## **System Requirements**

### **Hardware requirements**

* **OS:** Windows 10 or later
* **Processor:** Intel Core i5-4590/AMD FX 8350 equivalent or better
* **Memory:** 16 GB RAM minimum
* **Dedicated Graphics Card:** NVIDIA GeForce GTX 970, AMD Radeon R9 290 equivalent or better

### **VR headsets supported**

You do not need a VR headset to run VR-TAK, but in case you have one, these are the headsets we currently support:

* HTC VIVE, VIVE Pro, and Valve Index
* VIVE Cosmos requires VIVE software
* Oculus Rift S and S2
* Oculus Quest, Quest 2, and Quest 3
* Valve Index (SteamVR)
* Varjo (SteamVR)
