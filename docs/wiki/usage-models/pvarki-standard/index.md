PVARKI - Standard is not a do everything this way guide, it is general guide on how the some basic features are designed to be used. For more in depth ways of using the tools look in to [Use Cases](https://pvarki.getoutline.com/doc/use-cases-7bR2ASRf2x).

## @[Takserver RECON feed](./takserver-recon-feed)

Takserver automatically creates a RECON-feed for the servers default group

##  @[Takserver Groups](./takserver-groups)

Takserver automatically creates a default group and places all users to it.
