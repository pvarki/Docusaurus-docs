## What is RECON feed

Takservers RECON feed is meant for reviewed and verified intelligence and observations that the command wants to share to the whole server. 

RECON feed is meant to be subscribed and synchronized by everyone in the operation area of the server. The main use is to share immediate information about enemy and important information about friendly forces.

The basic settings for the RECON feed is to be shared to default group users and users subscribing will have read and write user rights. Admins can make changes and with bigger groups of users the RECON feed is recommended to be readonly for most of the users and write rights for command personnel that will manage the information on it.

## How to use RECON feed

Every user in PVARKI should be subscribed to the takservers RECON feed and have notifications enabled. The users situational awareness about friendly and enemy forces is kept up to date with RECON feed.

Command post users (HQ etc roles) are maintaining the feed with information from the groups own intelligence gathering, friendly forces intelligence and the Command RECON feed if they are part of bigger organization. CP users remove staled data, update changed data and input verified data to the feed.
