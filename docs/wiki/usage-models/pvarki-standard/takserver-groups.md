---
title: "Takserver Groups"
---

Groups are used to manage who sees and what. Users in the same group will share and view information about them selves and others. In PVARKI setup at start every user is in default group and admins can change them when needed. User can be part of many groups.

User can be part of a group in 3 ways. In (user sends \[write\] data to group), Out (user receives \[reads\] data from group) and Both (user send and receives data to/from group). These are managed with group (Both), group_WRITE (In) and group_READ (Out). [See here how to manage groups with PVARKI keycloak.](https://pvarki.getoutline.com/doc/keycloak-group-management-HbnhaALE1M)

Basic users don't see the groups and cannot change them. The management is for admin users and they can see the groups with different tak tools and takserver admin ui.
