![](./_media/b070d691-0e1e-406d-886f-24a78e9b3271.png "=189x") Locations of interest can be entered using the Point Dropper tool. The locations on map can be shown with different icons (i.e. MIL-STD-2525 symbols) for easy identification. The icons can also include data like notes or last seen information for additional functions.
