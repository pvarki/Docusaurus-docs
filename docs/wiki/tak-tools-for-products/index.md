---
title: "TAK Tools for Products"
---

TAK Products functions are mostly the same between different products (i.e. ATAK, WinTAK) and some of the additional plugins have been made for the different products. The functions being the same between products helps to bring together the ecosystem with takserver and other ways of connection between client devices.

TAK Tools are the functions/tools that are included in TAK products. 

TAK plugins are tak.gov, software company or community developed additions to TAK Products, that add more functions and/or combine multiple included functions together.


## TAK Tools:

* @[Bloodhound tool](./bloodhound-tool)
  * Tool for navigating from point to point.
* @[Contacts / GeoChat tool](./contacts-geochat-tool)
  * User contacts and chat.
* @[Point Dropper tool](./point-dropper-tool)
  * Marking interesting locations on map


## TAK Plugins:

* @[Data Sync -plugin](./data-sync-plugin)
  * Sharing data and keeping it synced between users
* @[TAK Replay -plugin](./tak-replay-plugin)
  * Record TAK events to timeline and replay events on map.
* @[UAS Tool -plugin](./uas-tool-plugin)
  * UAS TAK integration tool
* @[VNS -plugin](./vns-plugin)
  * Navigation data plugin for TAK
