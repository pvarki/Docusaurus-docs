---
title: "02-Deploy App x TAK"
---

Deploy App's TAK integration lets you deploy TAK to your users using Deploy App. Deploy App makes TAK deployment automatic and dynamic. Just spin up a Deploy App server and add users to it. Users get access to TAK via Deploy App's UI - presently they can download a client preference & cert zip that is to be put in their TAK clients.

### **Natural Language**

* FastAPI translation layer between Deploy App and TAK Server
* Presently supports two user groups, regular users and admins - admin in Deploy App is admin in TAK
* Can issue compatible TAK client zips with ATAK, iTAK, WinTAK and TAK Tracker
* Client zip contains dynamic configuration (eg. user callsigns, basic metric setup, map services & more
