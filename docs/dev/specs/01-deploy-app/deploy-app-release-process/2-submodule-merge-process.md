# Get your submodule PR merged -  Review Process

Once your PR is ready to be reviewed, set it to the **Ready to Review** -state. Announce this. Then the review & system testing process takes places as follows.

# Review process - responsible people

### Product owner/manager

1\. Arrange system testing with testers that can test target user behavior.

### Product Dev Team / Community


2. Review the PR, 1-2 reviews depending on how big a thing this is. **Reviews are much appreciated!** 

### Product Tech Lead:

3\. Voice yes/no for merging the PR after your own review (and conditions for a successful merge)

4\.  ***or*** based on review by team + their option on the changes.

### You/Developer:


5. Answer change requests by your reviewing teammates.
