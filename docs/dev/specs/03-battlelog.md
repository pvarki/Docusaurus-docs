Battlelog is an web app designed to let you manage your battle- or information space by logging and analyzing data. It has an API to enable its integration to various other products.

### **Natural Language**

* Light-weight frontend and REST API backend
* In Deploy App context, is accessible from Deploy App UI via link-button, with a valid Deploy App-issued mTLS certificate
* Lets you input log items, analyze it and search your data geospatially, temporarily and by tags
