Please report **bugs** and **vulns** you find! 

### Reporting Bugs

Create issue using the "Bug" template. 

Select correct repository:

* Found a bug in our TAK service? Report to [https://github.com/pvarki/docker-atak-server/issues](https://github.com/pvarki/docker-atak-server/issues)
* Found a bug in Deploy App's user interface? Report to [https://github.com/pvarki/rasenmaeher-ui/issues](https://github.com/pvarki/rasenmaeher-ui/issues)
* Found a bug but not sure where it belongs? Report to [https://github.com/pvarki/markdown-public-pm/issues](https://github.com/pvarki/markdown-public-pm/issues)
