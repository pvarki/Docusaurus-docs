# Deploy App Roadmap 

## H2/2025

### Core features

- [ ] **Core: New Integration API** - Enable delivering UI content via integration API. This makes it possible to not hardcode product content to UI, making it modular.
- [ ] **Docs: New Docs Platform done & Product Guides** made into it - Get rid of user guides written into Deploy App UI, instead do them in Docs that is shipped as static site. This simplifies developing Guides a lot, so that you don't have to ship them via Integration API and you can show them in the Docs Platform easily.
- [ ] **DX Documentation**: Write integration docs and reference implementation (Fake Product) so that it is very clear how to integrate new products into Deploy App.

### Product Integrations

- [ ] **New Product: MediaMTX Video Streaming** - New product integration that enables Deploy App users to create, watch and share video streams easily. Integrates nicely to TAK eg. UAS Tool and so to drone streams.
- [ ] **New Product: Battlelog** - App to manage data about your battle/-information space, analyse and search it effectively. Will enhance operating TAK in the future as it's much better to analyse and search eg. markers here than in TAK. 

### Infrastructure

- [ ] **K8s Deployment** - Helm Charts instead of Docker Compose. This lets us off from the one megacompose that always deploys with those services that are written into it. Thus we go towards ite
